# Publishing the GitHub profile

1. Open the public [Sodiols/Sodiols repository](https://github.com/Sodiols/Sodiols), or create it under that name.
2. Add `README.md` at the repository root and `assets/profile-cover.jpg` at the same relative path used here.
3. Commit the two files and open the [profile](https://github.com/Sodiols) to check the cover and links.

Edit the introduction, project descriptions, toolkit and contact links in Markdown. The cover pairs a custom nameplate with the TARA storefront artwork from Sodiol’s portfolio. To change it, replace the JPEG and update its alternative text in the README.

The other artwork and the Python generator belong to the previous animated design. Publishing this version only requires the two files listed above.
